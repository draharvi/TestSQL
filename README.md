# TestSQL

Приложение на C# с использованием Windows Forms для работы с базой данных MySQL.  
Позволяет создавать учетные записи пользователей с сохранением информации в базе данных.

---

## Функционал

- Регистрация нового пользователя (имя, фамилия, логин, пароль)
- Подключение к базе данных MySQL
- Простейший GUI с подсказками в полях ввода
- Возможность показывать/скрывать пароль

---

## Требования

- .NET Framework (версии, совместимой с Windows Forms)
- MySQL сервер
- MySQL Connector/NET (`MySql.Data` NuGet пакет)
